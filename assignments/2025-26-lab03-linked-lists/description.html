Objective

The same list interface, MyList<E>, can be implemented with different node structures. In this lab you implement it three times:

  • SinglyLinkedList<E>: nodes with one next reference, a head and a tail
  • CircularLinkedList<E>: a singly linked list whose last node points back to the first one (tail.next == head)
  • DoublyLinkedList<E>: nodes with prev and next references, a head and a tail

This lab practices keeping every link, head, tail and size correct in the special cases: the empty list, a one-element list, and the first and last positions.

Part 1: SinglyLinkedList<E>

FieldTypeRequirements
headNode<E>First node, or null when empty.
tailNode<E>Last node, or null when empty. tail.next is always null.
sizeintNumber of nodes.

Following next from head must visit exactly size nodes and end at tail. removeLast() has to walk to the node before tail and make it the new tail.

Part 2: CircularLinkedList<E>

FieldTypeRequirements
headNode<E>First node, or null when empty.
tailNode<E>Last node, or null when empty. tail.next is always head.
sizeintNumber of nodes.
  • A one-element list is a single node whose next is itself.
  • Starting at head and following next exactly size times must come back to head. No next is ever null while the list is not empty.
  • After every change that touches the first or the last node, set tail.next = head again.

Part 3: DoublyLinkedList<E>

FieldTypeRequirements
headDNode<E>First node, or null. head.prev is always null.
tailDNode<E>Last node, or null. tail.next is always null.
sizeintNumber of nodes.

For every node n except the last, n.next.prev == n. Walking backwards with prev from tail must give the elements in reverse order. removeLast() must be O(1) using tail.prev.

Example

MyList<Integer> list = new DoublyLinkedList<>();   // same results for all three classes
list.addLast(20);        // [20]
list.addFirst(10);       // [10, 20]
list.insertAt(2, 40);    // [10, 20, 40]
list.insertAt(2, 30);    // [10, 20, 30, 40]
list.insertAt(9, 99);    // invalid index: nothing happens
list.get(3);             // 40
list.get(4);             // null
list.set(0, 5);          // returns 10 -> [5, 20, 30, 40]
list.indexOf(30);        // 2
list.removeAt(1);        // returns 20 -> [5, 30, 40]
list.remove(40);         // true -> [5, 30]
list.remove(7);          // false
list.removeLast();       // 30 -> [5]
list.removeFirst();      // 5  -> []
list.removeFirst();      // null

Required Edge Cases

Your implementation must correctly handle:

  • Every add and remove method on an empty list and on a one-element list
  • Removing the only element (the list must be empty, and head/tail null), then adding again
  • insertAt at 0 and at size(), and the invalid indexes -1 and size() + 1
  • get, set and removeAt with -1 and size()
  • remove(o) of the first element, the last element (tail must be updated) and a missing element
  • Duplicates (only the first match counts)
  • clear() followed by new adds

Suggested Order

  1. SinglyLinkedList: size, isEmpty, addFirst, addLast, get, then the rest
  2. DoublyLinkedList (it is the same list plus prev links)
  3. CircularLinkedList
