CSE201 Data Structures
Lab 4: Linked Lists

Objective

A singly linked list stores its items in separate nodes. Each node holds one item and a reference to the next node. In this lab you build your own generic list, SinglyLinkedList<T>, with a head and a tail reference, and then use it to merge two sorted lists.

This lab practices:

  • Creating, linking and unlinking nodes without an array
  • Keeping head, tail and size correct in every special case (empty list, one item, first and last position)
  • Reversing a list in place by rewiring references

Part 1: SinglyLinkedList<T>

The starter gives you the private nested class Node<T> and the three private fields head (first node, or null), tail (last node, or null) and size. An empty list has head == null, tail == null and size == 0. Indexes start at 0.

Constructor

  • SinglyLinkedList(): creates an empty list.

Methods

MethodReturn typeRequired behavior
addFirst(T item)voidInserts item before the current first item.
addLast(T item)voidAppends item after the current last item. Must use tail, not walk the whole list.
add(int index, T item)voidInserts item so that it ends up at position index. Valid indexes are 0 to size() inclusive; otherwise IndexOutOfBoundsException.

removeLast()TRemoves and returns the last item. On an empty list, throws java.util.NoSuchElementException. Afterwards tail must point to the new last node.
remove(int index)TRemoves and returns the item at index. Same index rule as get.
indexOf(Object item)intIndex of the first item that is equals to item, or -1 if there is none.

reverse()voidReverses the list in place: the existing nodes are re-linked, no new nodes are created. head and tail swap roles. Does nothing to an empty list or a one-item list.

Example

SinglyLinkedList<Integer> list = new SinglyLinkedList<>();
list.addLast(20);          // [20]
list.addLast(30);          // [20, 30]
list.addFirst(10);         // [10, 20, 30]
list.add(1, 15);           // [10, 15, 20, 30]
list.get(2);               // 20
list.set(0, 5);            // returns 10 -> [5, 15, 20, 30]
list.indexOf(30);          // 3
list.removeLast();         // returns 30 -> [5, 15, 20]
list.remove(1);            // returns 15 -> [5, 20]
list.reverse();            // [20, 5]
list.addLast(7);           // [20, 5, 7]   (tail was updated by reverse)
list.get(3);               // IndexOutOfBoundsException

Part 2: Merging Sorted Lists

This is a static method of Lab04.

MethodReturn typeRequired behavior
mergeSorted(SinglyLinkedList<Integer> a, SinglyLinkedList<Integer> b)SinglyLinkedList<Integer>Both lists are sorted in ascending order. Returns a new list that contains all items of both lists in ascending order. Equal items from a come before equal items from b. a and b must be left unchanged. If either argument is null, throws IllegalArgumentException.

Examples

mergeSorted([1, 4, 9], [2, 3, 10])   ->  [1, 2, 3, 4, 9, 10]
mergeSorted([], [5, 6])               ->  [5, 6]
mergeSorted([2, 2], [2])              ->  [2, 2, 2]
mergeSorted(null, [1])                ->  IllegalArgumentException

Required Edge Cases

Your implementation must correctly handle:

  • An empty list, and a list with exactly one item, for every add and remove method
  • Removing the only item, then adding again (head and tail must both be reset)
  • Inserting at index 0 and at index size(), and invalid indexes -1 and size() (or size() + 1 for add)
  • removeLast() and remove(size() - 1): addLast must still work afterwards
  • removeAll when the matching items are at the front, at the end, next to each other, or when every item matches
  • reverse() followed by addLast and removeLast
