Objective

A red-black tree is a binary search tree in which every node is red or black. After every insertion the tree is repaired with recoloring and rotations so that these properties always hold:

  1. The root is black.
  2. A red node never has a red child (no two reds in a row).
  3. Every path from a node down to an empty (null) spot passes the same number of black nodes. null spots count as black.

Together they guarantee that the height is at most about 2 log2(n + 1). In this lab you implement insertion, including the fix-up after an insert. Removal is optional and not tested.

  • No duplicates: inserting an element that is already in the tree changes nothing. insert(null) changes nothing and contains(null) is false.
  • Do not throw exceptions. Only main and the given toString may produce text.

Example

Trees are written as value+color(left,right), with B = black, R = red and - = empty.

insert 50, 20, 10   (LL: rotateRight at 50)       ->  20B(10R,50R)
insert 10, 20, 30   (RR: rotateLeft at 10)        ->  20B(10R,30R)
insert 50, 10, 20   (LR)                           ->  20B(10R,50R)
insert 20, 10, 30, 5   (red uncle 30: recolor)     ->  20B(10B(5R,-),30B)

insert 1, 2, 3, 4, 5, 6, 7, 8:

                4B
             /      \
          2R          6R
         /  \        /  \
       1B    3B    5B    7B
                           \
                            8R

insert 33, 13, 53, 11, 21, 41, 61, 15, 31
  ->  33B(13R(11B,21B(15R,31R)),53B(41R,61R))

The given toString() prints the tree in level order with its null spots. The main method of the starter uses it.

Required Edge Cases

Your implementation must correctly handle:

  • The first insert into an empty tree (black root) and the empty tree itself
  • All four rotation cases (LL, RR, LR, RL), and rotations at the root (the root field must change)
  • A red uncle that makes the recoloring move up the tree, repeatedly
  • Duplicates and null
  • Long sequences, including sorted input: the three properties and all parent references must hold after every insert

Suggested Order

  1. isEmpty, size, isRed, getSibling, containsRec
  2. rotateLeft and rotateRight (with parent pointers)
  3. insert and insertRec without fixing (a plain BST)
  4. check, recolor, balance
