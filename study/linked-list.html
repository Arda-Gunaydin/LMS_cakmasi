Sık yapılan hatalar

  • Son elemanı silince tail'i güncellemeyi unutmak.
  • Liste boşalınca head ve tail'i ikisini de null yapmamak.
  • İlk eklenen elemanda head ile tail'i aynı düğüme bağlamamak.
  • reverse'de next'i bağlantıyı koparmadan önce saklamamak.
  • add(size, x) geçerli, get(size) geçersiz: sınırlar farklı.

reverse mantığı

Node prev = null, cur = head;
tail = head;
while (cur != null) {
    Node next = cur.next;   // önce sakla
    cur.next = prev;        // oku çevir
    prev = cur;
    cur = next;
}
head = prev;
