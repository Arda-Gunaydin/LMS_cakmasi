Objective

You implement the same complete binary tree twice: once in an array (ArrayBT) and once with linked nodes (LinkedBT). Both implement the interface ITree<E>.

A complete binary tree is filled level by level, left to right, like a heap but without any ordering rule. It is not a binary search tree: an element's position depends only on when it was inserted, never on its value.

This lab practices:

  • The array layout of a complete tree: the children of index i are 2i + 1 and 2i + 2
  • Recursive preorder, inorder and postorder traversals
  • Breadth-first traversal with a queue and depth-first traversal with a stack
  • Removing from a complete tree by moving the last element into the hole

The ITree<E> Interface

MethodReturn typeRequired behavior
size()intNumber of elements.
isEmpty()booleantrue when there are no elements.
insert(E element)voidPuts element in the next free position (level by level, left to right). null is ignored. Duplicates are allowed.
remove(E element)booleanFinds the first element equal to element in level order, replaces its value with the value of the last element, and deletes the last position. Returns true if something was removed, otherwise false (also for null).
contains(E element)booleantrue if some element equals it. contains(null) is false.
BFS(List<E> list)voidAppends the elements to list in level order.
DFS(List<E> list)voidAppends the elements in depth-first (preorder) order.
preorder(List<E> list)voidAppends root, left subtree, right subtree.
inorder(List<E> list)voidAppends left subtree, root, right subtree.
postorder(List<E> list)voidAppends left subtree, right subtree, root.

The traversal methods only add to the given list: they never clear it or remove anything from it. On an empty tree they add nothing.

Part 1: ArrayBT<E>

FieldTypeRequirements
dataE[]The tree in level order: the root is data[0]; the children of data[i] are data[2i + 1] and data[2i + 2]. Its length is the capacity given to the constructor and never changes.
sizeintElements are in data[0] to data[size - 1]; all other slots are null.
  • insert: writes to data[size]. When the array is full, the element is ignored.
  • remove: data[target] = data[size - 1], then data[size - 1] = null and size--.
  • preorder, inorder, postorder must use the recursive helpers recPreorder, recInorder, recPostorder. An index ≥ size is an empty subtree.
  • BFS simply walks data[0..size-1]. DFS may call preorder.

Part 2: LinkedBT<E>

Uses the given Node<E> (data, left, right) and the fields root and size. The shape of the tree must always be exactly the same as the ArrayBT with the same operations.

  • insert: breadth-first search from the root for the first node with a missing left (checked first) or right child, and attach the new node there. On an empty tree the new node becomes root.
  • remove: find the target by BFS, find the last node by BFS, copy the last node's value into the target, then detach the last node from its parent. Removing the only node makes root null.
  • BFS must use a Queue<Node<E>>.
  • DFS must use a Stack<Node<E>> and must not call the recursive preorder: pop a node, add it, push its right child and then its left child. The result equals the preorder.

Example

insert 1, 2, 3, 4, 5, 6        array: [1, 2, 3, 4, 5, 6]

            1
          /   \
         2     3
        / \   /
       4   5 6

BFS       [1, 2, 3, 4, 5, 6]
preorder  [1, 2, 4, 5, 3, 6]      (DFS gives the same)
inorder   [4, 2, 5, 1, 6, 3]
postorder [4, 5, 2, 6, 3, 1]

remove(2) -> true: 2 is replaced by the last element 6, and the last position is deleted

            1
          /   \
         6     3            array: [1, 6, 3, 4, 5, null]
        / \
       4   5

remove(9) -> false

Required Edge Cases

Your implementation must correctly handle:

  • Traversals and remove on an empty tree
  • Removing the root, the last element, and the only element; inserting again afterwards
  • Duplicates: remove removes only the first one in level order
  • insert(null), remove(null), contains(null)
  • Inserting into a full ArrayBT
  • A list that already contains elements: the traversal appends after them

Suggested Order

  1. ArrayBT: size, isEmpty, insert, BFS, then the recursive traversals, contains, remove
  2. LinkedBT: insert and BFS first, then the traversals, DFS with a stack, contains, remove
