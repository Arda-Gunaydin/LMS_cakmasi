Objective

A min-priority queue stores comparable elements and always gives back the smallest one first. You implement the interface PriorityQueue<E extends Comparable<E>> in two opposite ways:

  • UnsortedArrayPQ: insert is O(1) (just append), but min and removeMin are O(n) (scan for the minimum).
  • SortedLinkedPQ: insert is O(n) (find the right place), but min and removeMin are O(1) (the head is the minimum).

This lab practices comparing elements with compareTo, generic types with a bound, and the trade-off between the cost of inserting and the cost of removing.

Part 1: UnsortedArrayPQ<E>

FieldTypeRequirements
dataE[]Elements in data[0] to data[size - 1], in no particular order; every other slot is null. Fixed length DEFAULT_CAPACITY = 16.
sizeintNumber of elements.
  • insert: puts the element at data[size] (no sorting). If the array is full, it prints exactly PQ is full! (one line, with System.out.println) and does not insert.
  • findMinIndex() (private helper): scans data[0..size-1] and returns the index of the smallest element. If several elements are equally small, it returns the lowest of their indexes. Returns -1 when empty.
  • removeMin: saves data[m] (m = min index), moves the last element into slot m, sets the last slot to null, decreases size and returns the saved element. The other elements do not move.

Part 2: SortedLinkedPQ<E>

Uses the given Node<E> (data, next) and the fields head and size. The nodes are always sorted in ascending order, so head holds the smallest element.

  • insert: handles the three cases in the starter: empty list, insert before head, or walk until the right place. An element that is equal to elements already in the queue goes after them (first in, first out among equals).
  • min returns head.data; removeMin removes the head node. There is no capacity limit.

Example

UnsortedArrayPQ<Integer> pq = new UnsortedArrayPQ<>();
pq.insert(5); pq.insert(2); pq.insert(9); pq.insert(1); pq.insert(7);
// data = [5, 2, 9, 1, 7, null, ...]
pq.min();         // 1, data unchanged
pq.removeMin();   // 1: the last element 7 moves into slot 3 -> data = [5, 2, 9, 7, null, ...]
pq.removeMin();   // 2: the last element 7 moves into slot 1 -> data = [5, 7, 9, null, ...]
pq.size();        // 3

SortedLinkedPQ<Integer> s = new SortedLinkedPQ<>();
s.insert(5); s.insert(2); s.insert(9); s.insert(1);
// nodes: 1 -> 2 -> 5 -> 9
s.removeMin();    // 1
s.min();          // 2

Required Edge Cases

Your implementation must correctly handle:

  • min and removeMin on an empty queue, and after removing everything
  • Duplicates and elements that compare as equal (lowest index / first inserted comes out first)
  • The smallest element at the first index, at the last index, and inserting a new smallest or largest element into the sorted list
  • Inserting into a full UnsortedArrayPQ (prints PQ is full!, keeps 16 elements)
  • insert(null)
  • Any mix of inserts and removes: the elements always come out in ascending order

Suggested Order

  1. UnsortedArrayPQ: size, isEmpty, insert, findMinIndex, min, removeMin
  2. SortedLinkedPQ: size, isEmpty, insert, min, removeMin
