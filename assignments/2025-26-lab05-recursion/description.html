Objective

A recursive method solves a problem by calling itself on a smaller version of the same problem, until it reaches a base case that it can answer directly. In this lab you write ten small recursive methods on numbers, arrays, strings and linked lists.

This lab practices:

  • Choosing a base case and a recursive step that makes the problem smaller
  • Divide and conquer: fast exponentiation and binary search in O(log n)
  • Tail recursion with an accumulator
  • Recursion on linked lists, including reversing a list by re-linking its nodes

Part 1: Numbers and Arrays

factorial

public static long factorial(int n)

Returns n! = 1 × 2 × … × n. By definition 0! = 1.

  • A negative n throws IllegalArgumentException.
CallResult

factorial(5)120
factorial(20)2432902008176640000
factorial(-1)IllegalArgumentException

sum

public static int sum(int[] arr, int n)

Returns the sum of the first n elements of arr, that is arr[0] + … + arr[n - 1]. The array is not changed.

  • sum(arr, 0) is 0.
  • arr == null, n < 0 or n > arr.length throws IllegalArgumentException.
CallResult
sum([4, 1, 3, 9], 4)17
sum([4, 1, 3, 9], 3)8
sum([], 0)0
sum([1, 2], 3)IllegalArgumentException

power

public static long power(long base, int exp)

Returns baseexp using fast exponentiation: compute half = power(base, exp / 2) once, then return half * half (even exp) or half * half * base (odd exp). This makes only about log2(exp) recursive calls, so even exp = 1 000 000 000 must finish immediately without a StackOverflowError.

  • power(x, 0) is 1 for every x, including 0.
  • A negative exp throws IllegalArgumentException.
  • Overflow is not checked; use normal long arithmetic.
CallResult
power(2, 10)1024
power(-3, 3)-27
power(7, 0)1
power(1, 1000000000)1 (fast)
power(2, -1)IllegalArgumentException

binarySearch

public static int binarySearch(int[] arr, int target, int low, int high)

arr is sorted in ascending order and has no duplicates. Searches for target between indexes low and high (both inclusive) and returns its index, or -1 if it is not there. Look at the middle index mid = low + (high - low) / 2 and recurse into only one half.

  • When low > high the range is empty: return -1.
  • arr == null throws IllegalArgumentException.
  • Only indexes between low and high may be returned.
CallResult
binarySearch([1, 3, 5, 7, 9], 7, 0, 4)3
binarySearch([1, 3, 5, 7, 9], 4, 0, 4)-1
binarySearch([1, 3, 5, 7, 9], 9, 0, 2)-1 (9 is outside the range)
binarySearch([], 1, 0, -1)-1

fib

public static long fib(int n)

Returns the n-th Fibonacci number: fib(0) = 0, fib(1) = 1, and fib(n) = fib(n - 1) + fib(n - 2). The simple two-call recursion is fine; the tests only use n ≤ 30.

  • A negative n throws IllegalArgumentException.
CallResult
fib(0)0
fib(2)1
fib(10)55
fib(30)832040

tailSum

public static long tailSum(int n, long acc)

Tail-recursive summation: returns acc + 1 + 2 + … + n. The recursive call must be the very last thing the method does: return tailSum(n - 1, acc + n);. The usual first call is tailSum(n, 0).

  • When n ≤ 0 there is nothing to add: return acc.
CallResult
tailSum(4, 0)10
tailSum(3, 100)106
tailSum(0, 7)7
tailSum(-5, 7)7

reverse

public static String reverse(String s)

Returns a new string with the characters of s in reverse order. Strings of length 0 or 1 are their own reverse.

  • s == null throws IllegalArgumentException.

Part 3: Linked Lists

The given class Node has an int data and a Node next. A list is given by its first node (head); the empty list is null. buildList(1, 2, 3) builds the list 1 → 2 → 3 for you.

listSum

public static int listSum(Node head)

Returns the sum of all values in the list. The empty list (null) has sum 0.

contains

public static boolean contains(Node head, int target)

Returns true when some node holds target, otherwise false. The empty list contains nothing.

reverseList

public static Node reverseList(Node head)

Reverses the list in place and returns the new head (the old last node). Re-link the existing nodes; do not create new nodes. The old head becomes the last node, so its next must be null. reverseList(null) returns null, and a one-node list is returned unchanged.

CallResult

listSum(null)0
contains(5 → 8 → 2, 8)true
contains(null, 1)false
reverseList(1 → 2 → 3)the node 3, list 3 → 2 → 1

Required Edge Cases

Your implementation must correctly handle:

  • factorial(0), fib(0), fib(1), power(x, 0) and tailSum with n ≤ 0
  • Negative arguments to factorial, fib and power, and invalid n or a null array for sum
  • A very large exponent in power (only a logarithmic number of calls)
  • binarySearch for the first element, the last element, a missing value, a value outside low..high, and an empty range
  • The empty string, a one-character string and null in reverse
  • The empty list (null) and a one-node list in every Part 3 method

Suggested Order

  1. factorial, fib, tailSum, sum
  2. reverse, power, binarySearch
  3. listSum, contains, then reverseList
