Objective

A binary search tree keeps, for every node, smaller elements in the left subtree and larger elements in the right subtree. Inserting sorted data into a plain BST creates a long chain, so its operations become O(n). An AVL tree is a BST that re-balances itself with rotations after every insert and remove. It keeps its height O(log n).

This lab practices:

  • Recursive BST search, insert and remove (leaf, one child, two children)
  • Storing and updating the height in each node
  • The balance factor and the four rotation cases (LL, RR, LR, RL)
  • Inheritance: AVLTree extends BST and only overrides insertRec and removeRec

Part 2: AVLTree<E> extends BST<E>

The height of a node is the number of nodes on the longest path from it down to a leaf: a leaf has height 1 (set by the Node constructor) and an empty subtree has height 0. In an AVL tree every node's height field must always be correct.

MethodReturn typeRequired behavior
insertRec, removeRecNode<E>Same as the BST versions (same successor rule), but after changing a subtree: update the height of n and return balance(n).
height()intHeight of the whole tree: 0 when empty.
height(Node<E> n) (private)int0 for null, otherwise n.height.
updateHeight(Node<E> n) (private)voidn.height = 1 + max(height(n.left), height(n.right)).
getBalanceFactor(Node<E> n)intheight(n.left) - height(n.right); 0 for null.
balance(Node<E> n)Node<E>If the balance factor is > 1 (left-heavy): when getBalanceFactor(n.left) ≥ 0 do rotateRight(n), otherwise rotateLeftRight(n). If it is < -1 (right-heavy): when getBalanceFactor(n.right) ≤ 0 do rotateLeft(n), otherwise rotateRightLeft(n). Otherwise return n unchanged. Returns the new subtree root (null for null).
rotateLeft(Node<E> y)Node<E>x = y.right becomes the subtree root, y becomes x.left, and the old x.left becomes y.right. Update the height of y, then of x. Returns x.
rotateRight(Node<E> x)Node<E>The mirror image: y = x.left becomes the root, x becomes y.right, the old y.right becomes x.left. Update x, then y. Returns y.
rotateLeftRight(Node<E> n)Node<E>n.left = rotateLeft(n.left), then return rotateRight(n).
rotateRightLeft(Node<E> n)Node<E>n.right = rotateRight(n.right), then return rotateLeft(n).

The tests also call getBalanceFactor, balance and the rotations directly on small trees built from Node objects whose heights are already correct.

Required Edge Cases

Your implementation must correctly handle:

  • Empty trees: contains, remove, height(), findMin(null)
  • Duplicates and null (ignored; size unchanged)
  • Removing a leaf, a node with only a left or only a right child, a node with two children, and the root
  • All four AVL cases on insert, and rebalancing after remove (including a child with balance factor 0)
  • Correct height values in every AVL node after every operation
  • Long sequences: sorted inserts into an AVL tree must keep the height logarithmic

Suggested Order

  1. BST: findMin, containsRec, insertRec, removeRec
  2. AVLTree: height, updateHeight, getBalanceFactor, the rotations, balance
  3. AVLTree.insertRec, then AVLTree.removeRec
