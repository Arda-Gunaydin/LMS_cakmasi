CSE201 Data Structures
Lab 2: Arrays and the ScoreBook

Objective

Almost every data structure in this course is built on top of a plain array. In this lab you work with int[] and int[][] directly, and then build ScoreBook, a list of exam scores that grows by itself, the same way ArrayList does internally.

This lab practices three ideas that later data structures depend on:

  • Walking an array with an index, and staying inside its bounds
  • Returning a new array versus changing an array in place
  • Keeping a size that is different from the array's capacity, and growing the array when it is full

final class ArrayTools has a private constructor and only static methods. Unless a row says otherwise, a null array argument must cause IllegalArgumentException.

Part 2: ScoreBook

Create class ScoreBook. It stores exam scores (0 to 100) in a private int[] and keeps a separate private size. The positions from size to the end of the array are unused.

Constructors

  • ScoreBook(int initialCapacity): the array starts with this length. initialCapacity must be at least 1, otherwise IllegalArgumentException.
  • ScoreBook(): the same as ScoreBook(4).

Methods

MethodReturn typeRequired behavior
size()intNumber of scores stored.
capacity()intCurrent length of the internal array.
add(int score)voidAppends the score. When the array is full, first replaces it with an array of twice the length that holds the same scores.
get(int index)intThe score at index.
set(int index, int score)voidReplaces the score at index.
insertAt(int index, int score)voidInserts the score at index and shifts the later scores one position to the right. index may be from 0 to size(); size() means append. Grows the array like add.
removeAt(int index)intRemoves and returns the score at index, shifting the later scores one position to the left.
toArray()int[]A new array of length exactly size() with the scores in order. Changing it must not change the book.
letterCounts()int[]An array of length 5 with the number of A, B, C, D and F scores: A is 90–100, B is 80–89, C is 70–79, D is 60–69, F is 0–59.
toString()StringThe scores in order, for example [90, 75, 60]. An empty book gives [].

ScoreBook Rules

  • A score below 0 or above 100 in add, set or insertAt must throw IllegalArgumentException and leave the book unchanged.
  • get, set and removeAt accept indexes from 0 to size() - 1. Any other index throws IndexOutOfBoundsException, even when it is still inside the internal array.
  • insertAt with an index below 0 or above size() throws IndexOutOfBoundsException.
  • The capacity only grows, and only by doubling. Removing scores does not shrink it.

Example

ScoreBook book = new ScoreBook(2);   // size 0, capacity 2
book.add(90);                        // [90]            capacity 2
book.add(75);                        // [90, 75]        capacity 2
book.add(60);                        // [90, 75, 60]    capacity 4  (grew)
book.insertAt(0, 100);               // [100, 90, 75, 60]
book.removeAt(2);                    // returns 75 -> [100, 90, 60]
book.letterCounts();                 // [2, 0, 0, 1, 0]
book.get(3);                         // IndexOutOfBoundsException (size is 3)
book.add(101);                       // IllegalArgumentException, book unchanged

Required Edge Cases

Your implementation must correctly handle:

  • Empty arrays, and null arrays
  • Arrays with only negative numbers, and a maximum that appears twice
  • A rotation amount larger than the array length
  • A jagged 2D array
  • A ScoreBook with capacity 1 that has to grow several times
  • An index that is inside the internal array but not below size()
  • Scores exactly on the letter boundaries (90, 80, 70, 60, 59, 0, 100)
