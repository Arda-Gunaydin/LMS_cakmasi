Lab 4: Binary Search Trees

Objective

A binary search tree (BST) keeps values ordered so that, for every node, every value in its left subtree is smaller and every value in its right subtree is larger. In this lab you build your own generic BST, BST<T>, backed by your own node class — no built-in collection does the ordering for you.

This lab practices:

  • Writing a private, recursive node structure (value, left, right)
  • Recursive insert, search and delete that preserve the BST ordering invariant
  • Reasoning about tree shape: height, size, min/max, and an in-order traversal

Part 1: BST<T extends Comparable<T>>

Create class BST<T extends Comparable<T>>. Store values in your own private node class; do not expose the nodes outside BST. Ordering is decided with value.compareTo(other): the left subtree of a node holds only smaller values, the right subtree only larger ones, and no value appears twice.

Constructor

  • BST(): creates an empty tree.

Methods

MethodReturn typeRequired behavior
insert(T value)booleanInserts value at the position the BST ordering requires and returns true. If an equal value (compareTo == 0) is already present, the tree is left unchanged and this returns false. null causes IllegalArgumentException.
contains(T value)booleantrue when an equal value is in the tree. null causes IllegalArgumentException. Works on an empty tree (returns false).
remove(T value)booleanRemoves the node equal to value if present and returns true; otherwise leaves the tree unchanged and returns false. null causes IllegalArgumentException. A node with two children is replaced by its in-order successor (the smallest value in its right subtree); the rest of the tree keeps the BST ordering.
size()intNumber of values currently in the tree. 0 for an empty tree.
height()intLength of the longest root-to-leaf path, counted in edges: -1 for an empty tree, 0 for a tree with only a root, otherwise 1 + max(height(left subtree), height(right subtree)).
isEmpty()booleantrue exactly when size() is 0.
min()TThe smallest value in the tree. On an empty tree, throws java.util.NoSuchElementException.
max()TThe largest value in the tree. On an empty tree, throws java.util.NoSuchElementException.
toString()StringAn in-order traversal (so values appear in ascending order), formatted like [2, 5, 9]. An empty tree gives [].

Example

BST<Integer> t = new BST<>();     // size 0, height -1
t.insert(5);                        // [5]                       height 0
t.insert(2);                        // [2, 5]                    height 1
t.insert(8);                        // [2, 5, 8]                 height 1
t.insert(1);                        // [1, 2, 5, 8]              height 2
t.insert(5);                        // -> false, tree unchanged
t.contains(8);                      // -> true
t.contains(3);                      // -> false
t.min();                            // 1
t.max();                            // 8
t.remove(2);                        // -> true, tree becomes [1, 5, 8]
t.remove(2);                        // -> false, tree unchanged (2 is gone already)
new BST<Integer>().min();           // throws NoSuchElementException

Required Edge Cases

Your implementation must correctly handle:

  • An empty tree: size(), isEmpty(), height(), contains(), toString(), and min() / max() throwing
  • insert of a value already present (no duplicate, size unchanged)
  • remove of a leaf, a node with exactly one child, and a node with two children (successor case), including removing the root
  • remove of a value that is not in the tree
  • A tree built by inserting values in increasing order (a "chain" shape) to make sure height() is not assumed to be balanced
