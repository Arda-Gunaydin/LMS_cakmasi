CSE201 Data Structures
Lab 3: Stacks

Objective

A stack is a last-in-first-out (LIFO) collection: the last item pushed is the first one popped. In this lab you build your own array-based stack, ArrayStack<T>, and then use it to solve two classic stack problems: checking that brackets are balanced, and evaluating a postfix (Reverse Polish Notation) arithmetic expression.

This lab practices:

  • Implementing a generic, growable, array-backed collection
  • Choosing between push/pop/peek to solve a problem, instead of indexing directly
  • Reading exceptions from an empty or malformed structure as part of the contract, not as bugs

Part 1: ArrayStack<T>

Create class ArrayStack<T>. It stores its items in a private array and keeps a separate private size, the same growing pattern as an ArrayList: the array only grows, and only by doubling.

Constructors

  • ArrayStack(int initialCapacity): the internal array starts with this length. initialCapacity must be at least 1, otherwise IllegalArgumentException.
  • ArrayStack(): the same as ArrayStack(8).

Methods

MethodReturn typeRequired behavior
push(T item)voidPuts item on top of the stack. null causes IllegalArgumentException. When the array is full, first replaces it with an array of twice the length that holds the same items in the same order.
pop()TRemoves and returns the top item. On an empty stack, throws java.util.NoSuchElementException. Does not shrink the array.
peek()TReturns the top item without removing it. On an empty stack, throws java.util.NoSuchElementException.
isEmpty()booleantrue when the stack has no items.
size()intNumber of items currently on the stack.
capacity()intCurrent length of the internal array.
toString()StringThe items from bottom to top, for example after push(10), push(20), push(30): [10, 20, 30] (the last element shown is the top). An empty stack gives [].

Example

ArrayStack<Integer> s = new ArrayStack<>(2);   // size 0, capacity 2
s.push(10);                                     // [10]            capacity 2
s.push(20);                                     // [10, 20]        capacity 2
s.push(30);                                     // [10, 20, 30]    capacity 4  (grew)
s.peek();                                       // 30, stack unchanged
s.pop();                                        // returns 30 -> [10, 20]
s.pop();                                        // returns 20 -> [10]
s.isEmpty();                                    // false
s.pop(); s.pop();                               // second pop() throws NoSuchElementException

Part 2: Stack Applications

Both methods are static methods of Lab03, and both must be solved using an ArrayStack internally — not with recursion, indexes into the string, or any other collection.

MethodReturn typeRequired behavior
isBalanced(String expr)booleanScans expr left to right, looking only at the six bracket characters ( ) [ ] { } and ignoring every other character. Every closing bracket must match the type of the most recently unmatched opening bracket, and every opening bracket must eventually be closed. null causes IllegalArgumentException.
evaluatePostfix(String expr)intEvaluates a postfix (Reverse Polish Notation) expression whose tokens are separated by single spaces: integers (which may start with -, e.g. -3) and the operators + - * /. Division truncates toward zero, like normal int division. Dividing by zero throws ArithmeticException. null, an empty or blank string, or a malformed expression (too few operands for an operator, or more than one value left at the end) causes IllegalArgumentException.

Examples

isBalanced("(a + [b * c])")     ->  true
isBalanced("(a + [b)]")         ->  false   (] closes ( instead of [)
isBalanced(")(")                ->  false
isBalanced("")                  ->  true    (no brackets at all)

evaluatePostfix("3 4 +")        ->  7
evaluatePostfix("3 4 + 2 *")    ->  14
evaluatePostfix("6 2 /")        ->  3
evaluatePostfix("7 -2 *")       ->  -14
evaluatePostfix("4 0 /")        ->  ArithmeticException
evaluatePostfix("3 +")          ->  IllegalArgumentException  (only one operand available)
evaluatePostfix("3 4")          ->  IllegalArgumentException  (two values left, not one)

Required Edge Cases

Your implementation must correctly handle:

  • pop() and peek() on an empty stack
  • An ArrayStack with capacity 1 that has to grow several times
  • isBalanced with mismatched bracket types, a closing bracket with nothing open, and brackets nested inside other characters
  • evaluatePostfix with negative operands, integer division that truncates (for example 7 2 / should be 3, and -7 2 / should be -3), division by zero, and both kinds of malformed input
